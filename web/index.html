Log Ingestion & LogSQL Syntax

Standard JSON Ingestion Endpoint: 
curl -X POST http://localhost:8080/api/v1/logs \
  -H "Content-Type: application/json" \
  -d '[{"service":"auth","level":"INFO","message":"User login ok","trace_id":"trc-99"}]'
Grafana Loki / Vector / Fluent Bit Sink: 
curl -X POST http://localhost:8080/loki/api/v1/push \
  -H "Content-Type: application/json" \
  -d '{"streams":[{"stream":{"app":"billing"},"values":[["1700000000000000000","Charged card $49"]]}]}'
